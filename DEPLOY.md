# ClassMate — деплой на Railway

## 1. Загрузка
- Загрузите весь архив / подключите Git-репозиторий с этой папкой.

## 2. Postgres
- Добавьте плагин **PostgreSQL**.
- Переменная `DATABASE_URL` подставится автоматически.

## 3. Переменные
- `SECRET_KEY` — длинная случайная строка
- `DEBUG=false`
- `CORS_ORIGINS=*` (или ваш домен)

## 4. Start Command
```
python run.py
```

## 5. Аккаунты по умолчанию
| Логин | Пароль | Роль |
|-------|--------|------|
| admin | admin123 | Админ приложения |
| starosta | starosta123 | Староста (класс CLASS10A) |

Код приглашения класса: **CLASS10A**

## 6. После деплоя
- Откройте сайт → `Ctrl+Shift+R`
- Вход admin / admin123

## Возможности
- Ученик: чат, ДЗ, расписание, опросы, события, сборы, Reels, PRO/монеты
- Староста: управление классом, без Reels и без админки
- Админ: классы, пользователи, тарифы, заявки, рассылка, без классного чата
